Pillar 1: Foundations & 1-Bit Memory Storage

1.1 Combinational vs. Sequential Circuits

Parameter Combinational Logic Sequential Logic
Output Dependency Depends strictly on present inputs: \(Y = f(X)\) Depends on present inputs and past history: \(Y = f(X, Q_n)\)
Memory Element None. Pure gate-level forward evaluation. Present (Flip-Flops, Latches, or feedback delay loops).
Feedback Path Strictly prohibited (acyclic graph). Mandatory feedback loop creating bistable states.
Clock Signal Unclocked. Evaluates continuously. Synchronized by periodic clock pulses (or event-driven asynchronous).

1.2 Latches vs. Flip-Flops: Level vs. Edge Triggering

Latches are level-triggered storage elements. While the Enable signal is active (HIGH or LOW), the latch is transparent—any fluctuation at the input passes immediately to the output.

Flip-Flops are edge-triggered. They sample input data strictly during the brief transitional threshold of the clock—either rising edge (\(\uparrow\), positive-edge-triggered) or falling edge (\(\downarrow\), negative-edge-triggered).

1.3 S-R Latch: NOR vs. NAND Implementation & The Forbidden State

The Set-Reset latch is the fundamental 1-bit bistable multivibrator.

Active-HIGH S-R Latch (Cross-Coupled NOR Gates):
$$Q = \overline{R + \overline{Q}}, \quad \overline{Q} = \overline{S + Q}$$ • \(S=0, R=0 \implies Q_{n+1} = Q_n\) (Memory / Hold)
• \(S=1, R=0 \implies Q_{n+1} = 1\) (Set)
• \(S=0, R=1 \implies Q_{n+1} = 0\) (Reset)
• \(S=1, R=1 \implies Q = \overline{Q} = 0\) (Forbidden / Indeterminate State). Both outputs go LOW simultaneously, violating the mathematical complement rule. When inputs transition back to \(0,0\), race condition forces the circuit into an unpredictable state.
Active-LOW \(\overline{S}\)-\(\overline{R}\) Latch (Cross-Coupled NAND Gates):
• \(\overline{S}=1, \overline{R}=1 \implies Q_{n+1} = Q_n\) (Hold)
• \(\overline{S}=0, \overline{R}=1 \implies Q_{n+1} = 1\) (Set)
• \(\overline{S}=1, \overline{R}=0 \implies Q_{n+1} = 0\) (Reset)
• \(\overline{S}=0, \overline{R}=0 \implies Q = \overline{Q} = 1\) (Forbidden State).

1.4 Asynchronous Override Controls: Preset (\(\overline{Pr}\)) and Clear (\(\overline{Cr}\))

In production ICs (like IC 7474 and IC 7476), active-low \(\overline{Preset}\) and \(\overline{Clear}\) pins feed directly into the final cross-coupled latch gates, bypassing all clock-steering input transistors.

  • \(\overline{Pr} = 0, \overline{Cr} = 1 \implies Q = 1\) instantaneously (Asynchronous Set).
  • \(\overline{Pr} = 1, \overline{Cr} = 0 \implies Q = 0\) instantaneously (Asynchronous Clear/Reset).
  • \(\overline{Pr} = 1, \overline{Cr} = 1 \implies\) Normal clocked synchronous operation enabled.

Pillar 2: The Core 4 Flip-Flops & Internal Physics

2.1 Clocked S-R Flip-Flop

Adds steering AND/NAND gates enabled by the clock signal:

Characteristic Equation: \(Q_{n+1} = S + \overline{R}Q_n \quad \text{with constraint } S \cdot R = 0\)

2.2 J-K Flip-Flop: Eliminating the Forbidden State & The Toggle State

The J-K flip-flop solves the forbidden state by cross-feeding the outputs back to the input gating: \(S = J\overline{Q}\) and \(R = KQ\).

  • \(J=0, K=0 \implies Q_{n+1} = Q_n\) (Hold)
  • \(J=0, K=1 \implies Q_{n+1} = 0\) (Reset)
  • \(J=1, K=0 \implies Q_{n+1} = 1\) (Set)
  • \(J=1, K=1 \implies Q_{n+1} = \overline{Q}_n\) (Toggle Condition!)
Characteristic Equation: \(Q_{n+1} = J\overline{Q}_n + \overline{K}Q_n\)
TOP VIVA QUESTION: The Race-Around Condition in J-K Flip-Flops

What is it? In a level-triggered J-K flip-flop with \(J=1, K=1\), when the clock pulse duration \(t_p\) is greater than the internal propagation delay \(\Delta t\) (\(t_p > \Delta t\)), the output toggles back and forth multiple times during a single clock pulse, producing an unpredictable output at the clock's falling edge.

Condition to Avoid: \(t_p < \Delta t < T\) (where \(T\) is clock period).

Ultimate Hardware Solution: Master-Slave J-K Flip-Flop (IC 7476) or Edge-Triggered Flip-Flops. The Master stage responds when Clock=HIGH; the Slave stage isolates the output. The output updates strictly on the falling clock edge.

2.3 D-Type Flip-Flop (IC 74LS74)

The Data or Delay flip-flop ensures complementary inputs at all times by tying \(R = \overline{S} = \overline{D}\).

Characteristic Equation: \(Q_{n+1} = D\)

2.4 T-Type Flip-Flop (Toggle Element)

Formed by tying the J and K inputs together (\(J = K = T\)). It toggles the output on every clock pulse when \(T=1\), acting as a fundamental divide-by-2 frequency divider.

Characteristic Equation: \(Q_{n+1} = T \oplus Q_n = T\overline{Q}_n + \overline{T}Q_n\)

Pillar 3: Excitation Tables & Flip-Flop Conversions (The Design Core)

Characteristic Table: Tells you what the Next State (\(Q_{n+1}\)) will be given the current inputs.
Excitation Table: Tells you what Inputs are required to force a desired transition from Present State (\(Q_n\)) to Next State (\(Q_{n+1}\)).

3.1 The Master Excitation Table

Present State (\(Q_n\)) Next State (\(Q_{n+1}\)) Required S Required R Required J Required K Required D Required T
0 0 0 X 0 X 0 0
0 1 1 0 1 X 1 1
1 0 0 1 X 1 0 1
1 1 X 0 X 0 1 0

3.2 Universal 3-Step Flip-Flop Conversion Algorithm

  1. Step 1: Write the Truth / Characteristic Table of the Desired (Target) Flip-Flop.
  2. Step 2: In the same table, write the required inputs of the Available (Given) Flip-Flop for every \(Q_n \rightarrow Q_{n+1}\) transition using the Master Excitation Table.
  3. Step 3: Draw K-Maps for each Available input with the Target inputs and \(Q_n\) as variables to obtain the minimal drive equations.
Solved Conversion Examples:
• JK to D: \(J = D\), \(K = \overline{D}\) (Pass \(D\) through an inverter to \(K\)).
• JK to T: \(J = T\), \(K = T\) (Short \(J\) and \(K\) together).
• SR to JK: \(S = J\overline{Q}_n\), \(R = KQ_n\) (AND gates fed by feedback from outputs).

Pillar 4: Shift Registers & IC 74194

4.1 The 4 Primary Operating Modes

Mode Full Name Operating Principle Industry Applications
SISO Serial-In Serial-Out Bits enter serially one per clock pulse; exit serially after \(N\) clock pulses. Digital Delay Line: Delay time \(\Delta t = \frac{N}{f_{clk}}\).
SIPO Serial-In Parallel-Out Bits enter sequentially on 1 pin; all \(N\) bits read simultaneously. Deserializer, UART / SPI Receiver, I2C to parallel port expander.
PISO Parallel-In Serial-Out \(N\) bits loaded in 1 clock pulse; clocked out bit-by-bit serially. Serializer, UART / SPI Transmitter, telemetry data transmission.
PIPO Parallel-In Parallel-Out All \(N\) bits loaded simultaneously and available at output simultaneously. High-speed CPU ALU registers, temporary data bus buffers.

4.2 IC 74194 4-Bit Bidirectional Universal Shift Register

The standard MSI building block featuring parallel load, shift right, shift left, and hold capabilities:

\(\overline{MR}\) (Clear) Mode \(S_1\) Mode \(S_0\) Clock \(\uparrow\) Function Performed
0 X X X Asynchronous Reset: \(Q_A Q_B Q_C Q_D = 0000\)
1 0 0 X Hold: No change in stored bits.
1 0 1 \(\uparrow\) Shift Right: \(Q_A \leftarrow SR\_SER, Q_B \leftarrow Q_A, Q_C \leftarrow Q_B, Q_D \leftarrow Q_C\)
1 1 0 \(\uparrow\) Shift Left: \(Q_D \leftarrow SL\_SER, Q_C \leftarrow Q_D, Q_B \leftarrow Q_C, Q_A \leftarrow Q_B\)
1 1 1 \(\uparrow\) Parallel Load: \(Q_A \leftarrow A, Q_B \leftarrow B, Q_C \leftarrow C, Q_D \leftarrow D\)

4.3 Ring Counter vs. Johnson Counter

Attribute Ring Counter Johnson (Twisted-Ring) Counter
Feedback Loop Straight: \(Q_0 \rightarrow D_{in}\) Inverted: \(\overline{Q}_0 \rightarrow D_{in}\)
Number of States \(N\) states (for \(N\) flip-flops) \(2N\) states (doubles counting capacity!)
Unused States \(2^N - N\) (requires self-starting logic) \(2^N - 2N\)
Decoding Logic No decoder needed (each output is 1 state) Glitch-free 2-input AND gates
Applications Multiphase non-overlapping clock generation Quadrature signal generation, digital synthesizers

Pillar 5: Counters (Ripple vs. Synchronous)

5.1 Asynchronous (Ripple) Counters

In ripple counters, only the first flip-flop (LSB) receives the external clock. Subsequent flip-flops are clocked by the output of the preceding stage.

  • Cumulative Delay: Total propagation delay across \(N\) stages is \(t_{\text{total}} = N \cdot t_{pd}\).
  • Maximum Safe Frequency: $$f_{max} \le \frac{1}{N \cdot t_{pd} + T_s}$$
  • Decoding Glitches: Because outputs don't switch simultaneously, brief intermediate invalid states appear on the bus, triggering false output spikes in combinational decoders.
TTL Workhorse Counter ICs:
• IC 7490 (Decade Counter): Divide-by-2 (\(CLK_A\)) & Divide-by-5 (\(CLK_B\)). Wired for Mod-10 by connecting \(Q_A \rightarrow CLK_B\). Truncated to Mod-6 by wiring feedback \(Q_C \cdot Q_B\) to reset pins \(R_{0(1)}, R_{0(2)}\).
• IC 7493 (4-Bit Binary Counter): Divide-by-2 & Divide-by-8. Mod-16 sequence (0..15). Truncated to Mod-12 by wiring feedback \(Q_D \cdot Q_C\) to reset pins \(R_{0(1)}, R_{0(2)}\).

5.2 Synchronous Counters

All flip-flops share the same master clock simultaneously. State changes happen in parallel, eliminating cumulative ripple delay and decoding glitches.

3-Bit Synchronous Binary UP Counter Drive Equations:
• Flip-Flop 0 (LSB): \(J_0 = K_0 = 1\) (toggles every cycle)
• Flip-Flop 1: \(J_1 = K_1 = Q_0\)
• Flip-Flop 2 (MSB): \(J_2 = K_2 = Q_0 \cdot Q_1\)

5.3 Presettable Synchronous MSI Counters

  • IC 74160 / 74163: Fully synchronous 4-bit Decade / Binary counters with synchronous parallel load and Carry Lookahead (\(RCO\)) for high-speed cascading.
  • IC 74190 / 74191: Up/Down Synchronous Counters with direction control pin \(U/\overline{D}\).

Pillar 6: Finite State Machines (FSMs) & Real-World Physics

6.1 Mealy vs. Moore State Machine Models

Characteristic Mealy Machine Moore Machine
Output Equation \(Z = f(\text{Present State}, \text{Inputs})\) \(Z = f(\text{Present State})\)
State Count Generally requires fewer states. Often requires more states.
Timing Behavior Outputs can change asynchronously when inputs change between clock ticks (susceptible to glitches). Outputs update strictly synchronously on clock edges (glitch-free).

6.2 Sequence Detector Design (Example: Detecting `1010`)

Serial bit stream detector using Moore and Mealy models:

  • Overlapping Detection: An input sequence like `...101010...` generates detections at index 4 and index 6 (reusing the trailing `10`).
  • Non-Overlapping Detection: Once `1010` is detected, the detector resets to the initial state, requiring 4 brand new bits.

6.3 VLSI Timing Constraints: Setup, Hold & Metastability

Setup Time (\(t_s\)): The minimum time data input must remain stable before the active clock transition.
Hold Time (\(t_h\)): The minimum time data input must remain stable after the active clock transition.
Metastability: If input transitions within the aperture window (\(t_s + t_h\)), the flip-flop can enter a metastable state where the output lingers at an intermediate analog voltage (\(\approx V_{DD}/2\)) before randomly resolving to 0 or 1. Solved in digital design using dual-stage flip-flop synchronizers.
Clock Skew (\(\Delta t_{skew}\)) & Hold Violation Prevention:
When clock arrives later at flip-flop B than flip-flop A, hold time violation can occur unless: $$t_{\text{prop(min)}} \ge t_{\text{hold}} + \Delta t_{skew}$$

6.4 Real-World Practical Implementations

1. Mechanical Switch Debouncer: Mechanical switches bounce for 5–20 ms upon contact closure, generating dozens of false clock edges. A cross-coupled S-R latch (IC 74279) with an SPDT switch eliminates 100% of chatter.
2. 1-Bit Static RAM (SRAM) Cell: Composed of two cross-coupled inverters (6-transistor 6T cell) with NMOS pass transistors activated by Word Line (\(WL\)) and read/written via Bit Lines (\(BL, \overline{BL}\)).
3. Stepper Motor 4-Phase Wave Controller: A 4-bit ring counter generating non-overlapping wave drive sequence (`1000 -> 0100 -> 0010 -> 0001`) interfaced to a ULN2003 Darlington transistor array to drive inductive motor stator coils.
