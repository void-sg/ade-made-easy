STATE MACHINE DESIGN

1. Finite State Machine (FSM) Synthesis: Mealy vs. Moore

Sequential circuits with feedback are mathematically modeled as Finite State Machines (FSMs).

Parameter Mealy Model Moore Model
Output Equation \(Z = f(\text{Present State}, \text{Current Inputs})\) \(Z = f(\text{Present State})\)
State Requirement Often requires fewer states (outputs change on inputs immediately). May require one extra state for each output condition.
Clock Edge Synchronization Outputs can change asynchronously between clock edges if inputs change. Outputs change strictly on active clock edges (glitch-free).
Silicon Vulnerability Prone to combinational glitches and race conditions passing to outputs. Preferred in high-speed VLSI datapaths and microcontrollers.

5-Step FSM Synthesis Workflow

STEP 1

State Diagram

Construct directed graph showing states, transitions (\(X/Z\)), and reset state.

STEP 2

State Reduction

Eliminate redundant states using Implication Table or row equivalence.

STEP 3

State Assignment

Assign binary codes (Binary, Gray code, or One-Hot for FPGAs) to each state.

STEP 4

K-Map Minimization

Solve next-state excitation equations (\(D_n\) or \(J_n, K_n\)) and output logic.

STEP 5

RTL / Schematic

Instantiate flip-flops and gate networks or synthesize Verilog RTL.

Solved Example: 1010 Serial Sequence Detector

Specification: Detect the serial bit pattern 1010 arriving on input line \(X\). When detected, output \(Z=1\).

Overlapping vs. Non-Overlapping Detection

Input Stream: 1 0 1 0 1 0
• Overlapping: Output pulses twice (at index 4 and index 6) because the suffix 10 of the first match serves as the prefix 10 of the next.
• Non-Overlapping: Output pulses once; machine resets to idle state \(S_0\) after detection.

Mealy State Encoding & Equations

States: \(S_0\) (Reset, \(00\)), \(S_1\) (Got 1, \(01\)), \(S_2\) (Got 10, \(10\)), \(S_3\) (Got 101, \(11\)).
Using D Flip-Flops: \[D_1 = X \cdot Q_0 + \overline{X} \cdot Q_1 \cdot \overline{Q}_0\] \[D_0 = X \cdot \overline{Q}_1 \cdot \overline{Q}_0 + X \cdot Q_1 \cdot Q_0\] \[Z = \overline{X} \cdot Q_1 \cdot Q_0 \quad (\text{Asserts when in } S_3 \text{ and } X=0)\]

SILICON PHYSICS

2. VLSI Timing Constraints, Metastability & Clock Skew

The Golden Rules of Edge-Triggered Flip-Flops:
• Setup Time (\(t_s\)): Data input \(D\) must remain absolutely constant for at least \(t_s\) before the clock transition.
• Hold Time (\(t_h\)): Data input \(D\) must remain absolutely constant for at least \(t_h\) after the clock transition.
• Propagation Delay (\(t_{cq}\)): Time elapsed from the clock active edge until output \(Q\) updates.

Metastability & MTBF

When \(t_s\) or \(t_h\) is violated (e.g., asynchronous pushbutton pressed right on clock edge), the internal feedback transistors enter an unstable balance point (\(V_{DD}/2\)). The time to resolve exponentially follows: \[\text{MTBF} = \frac{e^{t_r / \tau}}{T_0 \cdot f_{clk} \cdot f_{data}}\] Industry Solution: Use a two-stage synchronizer flip-flop chain to provide settling time \(t_r\).

Clock Skew (\(\Delta t_{skew}\))

Difference in clock arrival times at two flip-flops due to trace length or buffer delay: \(\Delta t_{skew} = t_{clk2} - t_{clk1}\).
• Hold Time Race: If \(t_{cq} < t_h + \Delta t_{skew}\), new data races into the receiving flop before it held the old value!

Maximum Clock Frequency (\(f_{max}\))

The clock period must accommodate the slowest datapath: \[T_{clk} \ge t_{cq} + t_{comb(max)} + t_s - t_{skew}\] \[f_{max} = \frac{1}{T_{clk(min)}}\]

1. SPDT Switch Debouncer (IC 74279)

Mechanical switch contacts bounce mechanically for \(5\text{ms} - 20\text{ms}\) before settling. Connecting an un-debounced switch to a clock input produces 10 to 50 unintended clock pulses!

SR Latch Solution: The first mechanical closure flips the bistable latch immediately to the SET state. Subsequent bounces release the input, but the latch memory holds the output firmly HIGH until the switch contacts the alternate position.

💾

2. 1-Bit SRAM 6T CMOS Cell

Static Random Access Memory (SRAM) stores bits using cross-coupled CMOS inverters without requiring refresh cycles.

Architecture: Two cross-coupled inverters (4 transistors) store \(Q\) and \(\overline{Q}\). Two NMOS access transistors gated by the Word Line (\(WL\)) couple the internal nodes to complementary Bit Lines (\(BL\) and \(\overline{BL}\)) for high-speed differential read and write operations.

🔄

3. 4-Phase Stepper Motor Controller

Unipolar stepper motors require rotating energization sequences across 4 stator coils (Phases A, B, C, D).

Sequencing with Shift Registers:
• Wave Drive: 4-bit Ring Counter circulating 1000 → 0100 → 0010 → 0001.
• Full Step: Dual-phase drive 1100 → 0110 → 0011 → 1001 (maximum holding torque).
• Power Interface: Outputs drive ULN2003 high-current Darlington transistor arrays with inductive flyback suppression diodes.

module d_flip_flop_async ( input clk, input rst_n, // Active-low asynchronous reset input d, output reg q ); always @(posedge clk or negedge rst_n) begin if (!rst_n) q <= 1'b0; // Immediate async override else q <= d; // Clock synchronous transfer end endmodule

State Register (Clocked) always @(posedge clk or negedge rst_n) if (!rst_n) state <= S0; else state <= next_state; // 2. Next State Logic & Output always @(*) begin z = 1'b0; case (state) S0: next_state = x ? S1 : S0; S1: next_state = x ? S1 : S2; S2: next_state = x ? S3 : S0; S3: begin z = ~x; // Pulse HIGH on 1010 next_state = x ? S1 : S2; // Overlap loop end endcase end endmodule
