Pillar 1: Foundations & 1-Bit Memory Storage

Combinational vs. Sequential: While combinational circuits evaluate purely as \(Y = f(X)\), sequential circuits incorporate feedback memory where \(Y = f(X, Q_n)\).

The S-R Latch Forbidden / Indeterminate State:
• Active-HIGH (NOR): \(S=1, R=1 \implies Q = \overline{Q} = 0\) (violates complementary logic). When inputs drop simultaneously to 0,0, race condition occurs.
• Active-LOW (NAND): \(\overline{S}=0, \overline{R}=0 \implies Q = \overline{Q} = 1\) (forbidden state).

Asynchronous Override Controls: Preset (\(\overline{Pr}\)) & Clear (\(\overline{Cr}\))

In TTL ICs like 74LS74 and 74LS76, active-low \(\overline{Pr}\) and \(\overline{Cr}\) bypass the internal clock gating transistors and force outputs to \(Q=1\) or \(Q=0\) instantaneously.

Pillar 2: The Core 4 Flip-Flops & Internal Physics

Flip-Flop Type Standard IC Characteristic Equation Key Physical Property
Clocked S-R Discrete / 74279 \(Q_{n+1} = S + \overline{R}Q_n \quad (S \cdot R = 0)\) Basic gated memory; requires input interlock.
J-K Flip-Flop IC 7476 \(Q_{n+1} = J\overline{Q}_n + \overline{K}Q_n\) Feedback eliminates forbidden state; \(J=K=1\) creates Toggle State (\(Q_{n+1} = \overline{Q}_n\)).
D-Type Latch IC 7474 \(Q_{n+1} = D\) Single data line delay; eliminates all illegal states.
T-Type Toggle 7476 (\(J=K=T\)) \(Q_{n+1} = T \oplus Q_n\) Fundamental frequency divider (\(\div 2\) per clock pulse).
TOP VIVA TOPIC: The Race-Around Condition in J-K Latches

The Cause: In level-triggered J-K latches when \(J=K=1\), if the clock pulse width \(t_p\) exceeds the flip-flop propagation delay \(\Delta t\) (\(t_p > \Delta t\)), the output toggles back and forth multiple times during a single clock pulse, producing an unpredictable output when the clock falls.

Hardware Solution: Master-Slave J-K Flip-Flop (IC 7476). Master samples when Clock=HIGH; Slave updates outputs strictly on the falling clock edge (\(\downarrow\)), breaking the feedback loop.

Universal 3-Step Conversion Algorithm

  1. Step 1: Write the characteristic table of the target flip-flop.
  2. Step 2: Look up required inputs of the available flip-flop for each transition using the Master Excitation Table.
  3. Step 3: Solve K-Maps to derive the conversion logic:
    • JK to D: \(J = D, \quad K = \overline{D}\)
    • JK to T: \(J = T, \quad K = T\)
    • SR to JK: \(S = J\overline{Q}_n, \quad R = KQ_n\)

Pillar 4: Shift Registers & IC 74194

4 Operating Modes: SISO (delay lines), SIPO (UART RX deserializer), PISO (UART TX serializer), PIPO (bus registers).

IC 74194 Mode Selection Table

Mode \(S_1\) Mode \(S_0\) Active Function Description
0 0 Hold Outputs retain data state (\(Q_{n+1} = Q_n\)).
0 1 Shift Right Bits shift toward LSB (\(Q_A \leftarrow SR\_SER, Q_B \leftarrow Q_A, \dots\)).
1 0 Shift Left Bits shift toward MSB (\(Q_D \leftarrow SL\_SER, Q_C \leftarrow Q_D, \dots\)).
1 1 Parallel Load All 4 inputs (\(A, B, C, D\)) clocked simultaneously into register.
Ring vs. Johnson Counters:
• Ring Counter: Straight feedback (\(Q_0 \rightarrow D_{in}\)) gives \(N\) states.
• Johnson (Twisted-Ring) Counter: Inverted feedback (\(\overline{Q}_0 \rightarrow D_{in}\)) gives \(2N\) states with glitch-free 2-input AND decoding.

Pillar 5: Counters (Ripple vs. Synchronous)

Asynchronous (Ripple) Cumulative Delay

Because each stage clocks the next, propagation delays accumulate: \(t_{total} = N \cdot t_{pd}\). Maximum safe clock frequency:

\(f_{max} \le \frac{1}{N \cdot t_{pd} + T_s}\)

Synchronous UP Counter Derivation (3-Bit)

\(J_0 = K_0 = 1 \quad \mid \quad J_1 = K_1 = Q_0 \quad \mid \quad J_2 = K_2 = Q_0 \cdot Q_1\)

All flip-flops share the same master clock simultaneously, eliminating cumulative ripple delay and decoding glitches.

Pillar 6: FSMs & Real-World VLSI Physics

6.1 Mealy vs. Moore State Machine Models

Model Output Function Timing Behavior
Mealy \(Output = f(\text{Present State}, \text{Current Inputs})\) Asynchronous output changes can glitch when inputs switch between clock edges.
Moore \(Output = f(\text{Present State})\) Outputs are strictly synchronized with clock edges (glitch-free).

6.2 VLSI Timing Constraints

Setup Time (\(t_s\)): Minimum duration data input must stay stable before the active clock edge.
Hold Time (\(t_h\)): Minimum duration data input must stay stable after the active clock edge.
Metastability: When \(t_s\) or \(t_h\) is violated, internal bistable transistors enter an undefined analog equilibrium (\(\approx V_{DD}/2\)) before resolving unpredictably. Solved in silicon using dual-stage synchronizer flip-flops.

6.3 Real-World Applications

1. SPDT Switch Debouncer (IC 74279): Mechanical pushbuttons bounce for 5–20 ms upon contact closure, generating dozens of false clock edges. Cross-coupled SR latches eliminate 100% of contact bounce.
2. 1-Bit SRAM 6T Cell: Formed by cross-coupled inverters gated by Word Line (\(WL\)) access NMOS transistors onto complementary Bit Lines (\(BL, \overline{BL}\)).
