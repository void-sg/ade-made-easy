COMBINATIONAL LOGIC FOUNDATIONS

Theory, Boolean Synthesis & K-Map Minimization

Rigorous mathematical models for memoryless digital logic networks, canonical forms, prime implicant reduction, MSI arithmetic logic, and synthesizable Verilog architectures.

1. Standard Forms & Karnaugh Map Synthesis

Any arbitrary Boolean switching function can be represented canonically as a Sum-of-Products (SOP) of minterms or a Product-of-Sums (POS) of maxterms:

Canonical SOP: \(Y = \sum m(m_1, m_2, \dots) + d(d_1, \dots) \quad \Longleftrightarrow \quad \text{Canonical POS: } Y = \prod M(M_1, M_2, \dots) \cdot d(d_1, \dots)\)
Gray Code Adjacency in K-Maps:
K-Maps use reflected binary Gray code (`00, 01, 11, 10`) along rows and columns so that adjacent physical cells differ in exactly one literal. When cells are grouped in powers of two (\(2^k\)), \(k\) variables are eliminated using the Boolean identity \(A + \overline{A} = 1\).

Essential Prime Implicant (EPI) Selection Algorithm

  1. Identify all isolated 1s that cannot be grouped with any adjacent cell (single-cell PIs).
  2. Identify 1s that can only combine in a single direction to form groups of 2, 4, or 8 (Essential Prime Implicants).
  3. Check off minterms covered by EPIs; cover any remaining 1s using the largest possible overlapping groupings.
  4. Leverage Don't-Care conditions (\(d\)) by treating them as 1s only when they enlarge a group, and as 0s otherwise.

Shannon's Expansion Theorem for MUX Synthesis

Any \(n\)-variable Boolean function \(F(X_1, \dots, X_n)\) can be synthesized using an \(n-1\) select line multiplexer:

\(F(A, B, C) = \overline{A}\overline{B} \cdot F(0,0,C) + \overline{A}B \cdot F(0,1,C) + A\overline{B} \cdot F(1,0,C) + AB \cdot F(1,1,C)\)

Connect select lines to \(A, B\), and tie data inputs to \(0, 1, C,\) or \(\overline{C}\).

4. Practical Real-World Applications & Hardware Reality

4.1 Arithmetic Logic Unit (ALU) Datapath: IC 74181

The 74181 is a 4-bit slice ALU that performs 16 arithmetic operations (addition, subtraction, decrement, 2's complement) and 16 logic operations (AND, OR, XOR, NOT) governed by Mode Control (\(M\)) and 4 function select lines (\(S_3, S_2, S_1, S_0\)).

4.2 Synthesizable Verilog RTL Architecture

module adder_subtractor_4bit ( input [3:0] A, B, input M, // 0: Add, 1: Subtract (2's complement) output [3:0] Sum, output Cout ); wire [3:0] b_operand = B ^ {4{M}}; assign {Cout, Sum} = A + b_operand + M; endmodule

4.3 Hardware & Bench Physics

TTL Floating Input Physics: Standard 74LSxx bipolar TTL inputs float to a weak logic HIGH (\(\approx 1.4\text{V} - 1.8\text{V}\)) because the multi-emitter NPN transistor base is pulled up to \(V_{CC}\) via an internal \(4\text{k}\Omega\) resistor. Leaving unused inputs floating invites noise pick-up; always tie unused pins to \(V_{CC}\) via a \(1\text{k}\Omega\) pull-up or directly to GND.
