Combinational Applications, ALU & RTL Architecture

Bridge classroom Boolean algebra with industrial silicon design. Explore multi-operation Arithmetic Logic Units (ALUs), priority encoder keyboard scanners, synthesizable Verilog RTL, and physical breadboard constraints.

DATAPATH CORE

1. Arithmetic Logic Unit (ALU) Datapath: IC 74181

The IC 74181 was the first complete 4-bit slice ALU implemented on a single TTL chip, forming the central computational core of historic minicomputers such as the DEC PDP-11 and Data General Nova. It evaluates 16 arithmetic operations and 16 Boolean logic functions on two 4-bit words (\(A_3..A_0\) and \(B_3..B_0\)).

Mode Select (\(M\))

\(M = 1\) (Logic Mode): Carry generation internal stages are disabled. Functions like AND, OR, XOR, NOR, and NOT are generated purely bit-wise without carry propagation.

\(M = 0\) (Arithmetic Mode): Full carry lookahead stages are engaged. Addition, subtraction, increment, decrement, and 2's complement arithmetic execute with high-speed carry lookahead.

Function Select Lines (\(S_3, S_2, S_1, S_0\))

The 4 select lines specify 1 of 16 operations:
• \(S = 1001\): Addition \(F = A + B\) (when \(M=0, C_n=1\))
• \(S = 0110\): Subtraction \(F = A - B - 1\)
• \(S = 1011\): Bitwise AND \(F = A \cdot B\) (when \(M=1\))
• \(S = 1110\): Bitwise OR \(F = A + B\)
• \(S = 0110\): Bitwise XOR \(F = A \oplus B\)

Carry Lookahead Outputs (\(G, P\))

Generate (\(G\)) and Propagate (\(P\)) pins allow cascading multiple 74181 chips with the IC 74182 Lookahead Carry Generator to perform 16-bit, 32-bit, or 64-bit high-speed arithmetic without ripple-carry bottlenecks.

INPUT SUBSYSTEMS

2. Priority Encoders in Microprocessor & Keyboard Interfacing

Standard encoders fail if two or more input lines go active simultaneously. A Priority Encoder establishes a strict hierarchy: the output code corresponds to the highest-order active input, ignoring all lower inputs.

IC Number Type Active Level Key Features & Applications
IC 74147 10-Line Decimal to 4-Line BCD Active-LOW (\(\overline{1}..\overline{9}\)) Translates calculator / keypad pushbuttons into 4-bit 8421 BCD code. If keys 3 and 7 are pressed together, code for 7 (\(1000\) active-low) appears.
IC 74148 8-Line Octal to 3-Line Binary Active-LOW (\(\overline{0}..\overline{7}\)) Features Enable In (\(\overline{EI}\)), Enable Out (\(\overline{EO}\)), and Group Select (\(\overline{GS}\)) pins for cascading to 16, 32, or 64 interrupt request lines (IRQs).
Microprocessor Interrupt Handling: In real computer architectures (such as x86 PIC 8259 or ARM NVIC), external peripherals (timers, keyboards, network cards) assert interrupt requests (IRQs). The priority encoder ensures that critical hardware faults (IRQ 0) preempt lower-priority tasks (serial ports, user keyboards).
HARDWARE DESCRIPTION LANGUAGE

3. Synthesizable Verilog RTL Architectures

In modern electronic design automation (EDA), schematics are described in synthesizable Verilog or VHDL, targeted to FPGAs or ASICs:

4-Bit Adder / Subtractor (IC 7483 Equivalent)

module adder_subtractor_4bit ( input [3:0] A, B, input M, // 0: Add, 1: Subtract output [3:0] Sum, output Cout ); // XOR gates form controlled 1s/2s complement inverter wire [3:0] b_operand = B ^ {4{M}}; assign {Cout, Sum} = A + b_operand + M; endmodule

8:1 Multiplexer with Strobe (IC 74151 Equivalent)

module mux_8to1 ( input [7:0] D, // 8 Data Inputs input [2:0] Sel, // 3 Select Lines input E_n, // Active-low Strobe Enable output Y, // True output output W // Inverted output ); assign Y = (~E_n) ? D[Sel] : 1'b0; assign W = ~Y; endmodule
HARDWARE PHYSICS

4. Physical Electronics & Breadboard Reality

TTL Floating Input Physics

In standard 74LSxx bipolar TTL chips, input pins are connected to multi-emitter NPN transistors pulled up to \(V_{CC}\) via internal \(4\text{k}\Omega\) resistors. An open/floating pin reads as a weak HIGH (\(1.4\text{V}-1.8\text{V}\)), but acts as an antenna picking up \(50\text{Hz}\) mains hum. Rule: Always tie unused inputs to \(V_{CC}\) through \(1\text{k}\Omega\) or directly to GND.

Fan-Out & Current Budgeting

Fan-Out is the maximum number of standard logic inputs a single output can reliably drive without voltage degradation: \[\text{Fan-Out} = \min\left( \frac{I_{OH}}{I_{IH}}, \frac{I_{OL}}{I_{IL}} \right)\] For 74LS TTL: \(I_{OL} = 8\text{mA}, I_{IL} = 0.4\text{mA} \implies \text{Fan-Out} = 20\) standard 74LS loads.

Decoupling & Ground Bounce

When totem-pole output transistors switch, momentary conduction overlap causes rapid current transients (\(di/dt\)). Stray breadboard wire inductance generates ground bounce: \(V_{bounce} = L \cdot \frac{di}{dt}\). Place a \(0.1\mu\text{F}\) ceramic capacitor directly across pins 14 (\(V_{CC}\)) and 7 (GND) of each IC.
